**Methodology.** A key counts as *used* when it appears as a static string literal in
`t()` / `tr()` / `translateOrFallback(_, …)` / `lookup(_, …)` under `frontend/js/`, or in
`data-i18n*` / `data-tip` attributes in `frontend/index.html` and `frontend/js/` (git-tracked

regexes as `frontend/tests/no_missing_t_call_keys.spec.js` and
`frontend/tests/no_missing_i18n_keys.spec.js`. Template-literal keys are not resolvable
statically and are not counted. *Missing* = used but absent from
`frontend/i18n/app_i18n_en.json`. Per-locale parity against English is reported by
`node scripts/i18n-audit.mjs`, not here.
