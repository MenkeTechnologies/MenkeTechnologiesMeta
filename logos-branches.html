The rule

With four siblings the system has to be a rule, not four separate ideas. The hex package and the MT monogram are identical in all five marks — that is what makes them read as one family. The differentiator comes from a property of the hexagon itself: it leaves its four diagonal corners empty. Each branch fills that void with a different glyph type — angular, curved, solid, round — at the same footprint, on the same grid, in its own accent. Anything drawn tight against the package instead reads as a double-stroke mistake rather than a decision, which is why the detail lives out in the corners with real air around it.

More options

Every corner glyph below is a valid candidate under the same rule, so any of them can be swapped into any branch — these are grouped by the branch they suit, not restricted to it. The current pick in each row is marked. All are drawn once in the top-left void and mirrored into the other three, so the four corners can never drift out of symmetry.
