MENKE Technologies

The read · selected 05 DIE

Nine marks cut from the stack. 05 DIE is the one that shipped.

Every mark below is an M constructed from something that already exists in the stack — a prompt, a redirect operator, a block cursor, a copper trace, a silicon die, a pipe, a bytecode stack. Nine directions, each shown on the void ground and on paper, because a corporate mark has to survive both.

Palette and geometry are inherited from the existing app icons rather than invented, so the corporate mark lands in the same family as the products it sits above. 05 DIE was selected: an MT monogram inside a hex package with pin stubs, the only mark here carrying both initials. Production files are in branding/.

The marks

Left tile: void ground, neon cyan. Right tile: paper ground with the darkened cyan — bright #00b0ff fails on white, so the system carries a paper-safe variant. Toggle the construction grid to check every vertex lands on the 8-unit lattice.

Geometry

Grid
64 × 64 units, all vertices on the 8-unit lattice.
Diagonals
Exactly 45°. The apex sits 18 units in and 18 units down.
Stroke
6 units, miter joins, square caps. Never rounded.
Clear space
One cursor width — 9 units — on every side.

Type

Wordmark
Monospace, 700, +0.04em. MENKE set solid; TECHNOLOGIES tracked to +0.46em to match the cap width above it.
Why mono
A company that builds shells sets its own name in the face its users read all day.
Lockup
Mark height equals the two-line wordmark height. Gap equals one mark width ÷ 4.
